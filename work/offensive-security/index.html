Offensive Security

Understanding the attack well enough to build the detection — and reporting it so it actually gets fixed.

I don't want to be a penetration tester. I want to be the defender who knows exactly what the attack looks like from the other side, because that's what makes a detection rule good instead of theoretical.

Everything here runs against infrastructure I own or deliberately vulnerable targets built for the purpose.
