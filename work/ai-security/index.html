Domain

AI Security

Securing systems that put a language model between untrusted input and real business actions.

I lead secure AI enablement for 1,500+ users in a regulated banking environment, which mostly means answering an uncomfortable question: what happens when a model with access to sensitive data is handed input from someone who wants it to misbehave?

Projects 04 and 05 in the cloud series are the live testbed — both put an LLM in the path of untrusted text, so both get a genuine adversarial security layer rather than a disclaimer.

Grounding

What this is built on

Grounded in production experience: leading secure AI enablement across 1,500+ enterprise users at Sunflower Bank — engineering DLP controls and data-loss policies for Microsoft Copilot to prevent NPI leakage under GLBA — plus AI-driven phishing detection tuning in Proofpoint at FirstBank that cut manual investigation 30%. Framework familiarity: NIST AI RMF.
